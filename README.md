# Hybrid Shorts Motion Upgrade

## What this version changes
- Animated character gestures: alternating arm gestures, hand motion, subtle body bob and leg swing.
- Animated science accents: pulsing highlights, drifting particles and a moving chart sweep.
- Gentle camera push-in on each scene.
- Cleaner scene panels; removes tiny labels that competed with captions.
- Final output is upscaled to 1080x1920 at 30 FPS.
- Adaptive narration timing retained.
- Human review only; no automatic YouTube upload.

## Honest capability statement
This is procedural 2.5D motion graphics made with Python/Pillow and FFmpeg. It is more animated than the previous static illustrations, but it is not full 3D character animation, generative video, realistic lip-sync or AI-created cinematic footage.

## Android GitHub replacement
Replace these three complete files in the existing repository:
1. `main.py`
2. `requirements.txt`
3. `.github/workflows/daily-draft.yml`

Keep existing repository secret `GEMINI_API_KEY` and variables `CHANNEL_TOPIC`, `VIDEO_LANGUAGE`, `VIDEO_DURATION`, and `GEMINI_MODEL`. The workflow keeps `ESPEAK_RATE` at 135.

Steps:
1. Download and extract this ZIP on Android.
2. On GitHub, open each corresponding file and use Edit.
3. Select all old contents and paste the complete replacement file.
4. Commit directly to `main`.
5. After all three commits, open Actions > Generate daily Short draft > Run workflow on `main`.
6. Download the artifact from that exact run and inspect `SHORT_REVIEW_ME.mp4`.
