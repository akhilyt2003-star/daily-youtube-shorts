# Hybrid Shorts generator upgrade

Creates 720x1280 vertical Shorts with:
- Six linked story scenes generated by Gemini.
- A recurring cartoon guide, illustrated anatomy/objects/environments, and schematic science visuals.
- Slow push-in and lateral camera motion using FFmpeg.
- Yellow karaoke-style word highlighting with per-scene timing estimates.
- Human review package; no automatic YouTube upload.

## Honest visual limitation
This is a low-cost hybrid 2.5D motion-graphics pipeline, not full AI-generated 3D character animation. It uses original Pillow-drawn layered illustrations, shadows/highlights, schematic science graphics and camera movement. It does not generate realistic 3D models, lip-sync or frame-by-frame character acting.

## Replace files in your existing GitHub repository
Replace these complete files:
1. `main.py`
2. `requirements.txt`
3. `.github/workflows/daily-draft.yml`

Keep the existing `GEMINI_API_KEY` secret and repository variables `CHANNEL_TOPIC`, `VIDEO_LANGUAGE`, `VIDEO_DURATION`.
If you already created a `GEMINI_MODEL` repository variable and the previous workflow worked, keep the same value. If not, this code uses `gemini-3.5-flash-lite` as its default; Gemini model availability can change, so retain the model that actually worked for your project.

## Run
GitHub repository > Actions > Generate daily Short draft > Run workflow.
Download `daily-short-review`, extract it, then inspect `SHORT_REVIEW_ME.mp4`, `script.txt`, `metadata.json` and `review_checklist.txt`.

## Budget
No paid image, video, or voice-generation API is used. Python, Pillow, FFmpeg and eSpeak NG are open-source. Gemini API usage depends on your account's current free quota; free quotas and GitHub Actions availability are subject to provider limits. No guarantee of unlimited free generation.

## Important
The generator intentionally does not upload to YouTube. Review the facts, narration, captions and visuals, then upload/schedule manually in YouTube Studio.
