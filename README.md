# Hybrid Motion v2 — Neural TTS upgrade

This is a complete replacement set for the existing `daily-youtube-shorts` repository.

## What changes
- Replaces eSpeak NG with `edge-tts` neural narration.
- Uses `en-US-GuyNeural` (male US English).
- Synthesizes each scene separately, retries transient failures, converts each MP3 to a consistent WAV format, and measures the combined narration duration.
- Keeps the existing Gemini script generation, hybrid 2.5D motion graphics, captions, 1080x1920 export, and manual review workflow.
- Does not publish automatically.

## Budget and service caveat
No paid TTS API key or subscription is added. `edge-tts` is a community Python client for Microsoft's online Edge text-to-speech service; it requires internet access and is not an official SLA-backed free API. The endpoint may change, throttle, or block automated requests. GitHub Actions and Gemini free-tier limits also apply. Therefore this design adds no planned recurring TTS charge, but cannot guarantee unlimited free use or uninterrupted availability.

## Replace these files in the repository
1. `main.py`
2. `requirements.txt`
3. `.github/workflows/daily-draft.yml`

Keep the existing repository secret `GEMINI_API_KEY` and variables `CHANNEL_TOPIC`, `VIDEO_LANGUAGE`, `VIDEO_DURATION`, and `GEMINI_MODEL`. No new secret or repository variable is required.

## Expected voice
`en-US-GuyNeural`, a male US English neural voice. The workflow has a 35–45 second audio duration check and allows only modest speech-rate changes to avoid unnatural pacing.

## Important
The video visuals remain procedural hybrid 2.5D graphics, not full 3D animation. Captions are still estimated from word lengths and scene durations; they are not generated by forced word-level alignment. Review the finished MP4 before uploading.
